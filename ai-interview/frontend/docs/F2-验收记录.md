## 2. 核心实现口径

| 主题 | 落地 |
|---|---|
| 轮次唯一事实源 | `detail.currentRound`（0-based）；`utils/round.ts` 的 `computeAwaitingAnswer` 只在 `WAITING_USER` + 当前轮 AI 数 > USER 数 + 最后一条为 AI 时可作答；从不按消息总数推轮次 |
| 追问计数 | 当前轮 AI 消息数 - 1，clamp 0~3；FINISHED/TIMEOUT 进度显示 `plannedRounds/plannedRounds` |
| 异步契约 | 提交/finish 只当作“受理”；AI 产出以 WS 为通知、REST `detail+messages` 为事实源；每次事件先 `applyWsEvent` 再统一 refresh 对账 |
| 轮询 | 提交后 1s→2s→3s，60s 上限；WS 断开时 2s 固定轮询兜底；页面隐藏暂停，恢复可见立即对账 |
| WS 重连 | 1/2/4/8/15s 退避 × 8；4401 清登录并回登录页；手动“重连”重置计数；终态主动关闭不重连 |
| 倒计时 | 初始取 `detail.remainSeconds`，本地每秒递减，TIMER/每次 detail 刷新用服务端值校准；≤60s 红色警示；到 0 禁用提交等待收卷 |
| 乐观气泡 | 提交即插入负 id USER 气泡；服务端消息出现且内容/轮次一致时清除；失败标记“发送失败，内容已保留”，不自动重发 |
| 草稿 | 按 `interview-draft:{sessionId}:{roundNo}` 存储；刷新恢复；提交成功/终态清理；不存 token/密码 |
| 终态 | FINISHED/TIMEOUT：报告生成中 + 总分（若有）+ 查看报告/返回历史；ABORTED：不生成报告 + 重新开始/返回历史；停计时、关 WS、清草稿 |
| 语音能力 | F2 只做 `MediaRecorder/getUserMedia/Web Speech/webm MIME` 检测与 AUDIO 入口；录音/转写 UI 归 F4，房间内先提供文字兜底并明确提示 |

### 边界与降级手工/自动验证

- **刷新恢复**：房间刷新后从 `detail+messages` 重建；输入框重新可用；草稿按轮次恢复（手工：输入未提交文本 → reload → 文本仍在）。
- **双击提交**：`store.submitText` 在 `submitting=true` 时直接抛 10005，不发起第二次 API；单测断言 `submitTextAnswer` 只调用 1 次。
- **他端结束**：两个标签页同会话，B 页 finish，A 页收到 `PROGRESS(FINISHED)` 后刷新进入终态（E2E #4）。
- **超时**：直接打开历史 TIMEOUT 会话（id=6）→ “时间到，系统已自动收卷” + 总分 + 报告/历史 CTA；计时器隐藏；后端 `InterviewTextFlowIT.timeout` 覆盖自动收卷。
- **40401**：`/interview/999999` → “面试记录不存在或无权访问” + traceId + 重试/返回历史；`/positions/999` → 岗位空态。
- **WS 4401**：`useWebSocket` 单测断言只回调一次、不重连；HTTP 401 与 WS 4401 均接全局登录失效。
- **移动端**：390×844 房间首屏保留题面与倒计时，不自动聚焦把题面顶出屏幕；单列布局无横向滚动（截图 12）。

## 6. 与计划的偏差与说明

| # | 偏差 | 原因/处理 |
|---|---|---|
| 1 | 终态（FINISHED/TIMEOUT/ABORTED）停留在房间展示结果与“查看报告/返回历史”CTA，不自动跳转报告页 | 报告页属 F3-1（含 10004 轮询/重试）；F2 直接跳到 F3 占位页会破坏演示体验。终态行为、停计时、关 WS、禁输入、清草稿均已实现；F3 落地后在 `handleTerminal` 增加报告就绪轮询与自动跳转即可 |
| 2 | 设置页允许选择 AUDIO，但房间录音/转写 UI 未实现，暂以文字作答兜底并提示“F4 接入” | F2 范围只含文字作答（计划 §11.3）；后端 TEXT 流程对 AUDIO 会话同样接受文字，报告不会伪造 voice 维度，避免 F2 阻塞 F4 |
| 3 | E2E 为 6 条 F2 冒烟，未覆盖管理端/语音/报告（计划 E2E 全套 10 条） | 管理端 F5、语音 F4、报告 F3 尚未交付；F2-8 要求的文字主链路、刷新、断线、他端结束已覆盖；F6 扩到 ≥6 条全链路 |
| 4 | 单测覆盖率 59.32%，低于计划 70% 目标 | F1 为 47.57%，F2 新增核心 `round/draft` 100%、`stores/interview` 80.31%；覆盖阈值与 API 模块补齐排期 F6-1 |
| 5 | 超时未做自动化 E2E（后端最短时长 15 分钟） | 用历史 TIMEOUT 会话手工验证终态 + 后端 `InterviewTextFlowIT.timeout` 自动收卷；F6 可在测试环境注入过期截止时间做 E2E |
| 6 | 修复了 F1 遗留的 Element Plus 主色 `text/plain` 按钮样式问题 | `element-overrides.scss` 曾把 `.el-button--primary` 的蓝色渐变套到 `is-text/is-plain`，导致蓝字蓝底不可见；F2 首页/岗位/房间按钮暴露后已修复并复验 |
