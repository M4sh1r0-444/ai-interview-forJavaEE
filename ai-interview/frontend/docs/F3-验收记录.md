## 2. 核心实现口径

| 主题 | 落地 |
|---|---|
| 报告唯一事实源 | `GET /interviews/{id}/report`；`stores/report` 按 `sessionId` 缓存，避免返回报告页重复加载；数据不落 localStorage |
| 10004 轮询 | 1s → 2s → 3s 后固定 3s；60s 上限；页面隐藏暂停、恢复可见立即补一次；同时连接 WS 监听 `REPORT_READY` 立即拉取（WS 不可用则纯轮询） |
| 重试 | 60s 仍未就绪或 WS `ERROR` 时展示「重新生成报告」→ `POST finish`（后端幂等，已存在报告直接返回 reportId）→ 清缓存并重新轮询；页面级 `retrying` 锁防重复 |
| 异常分流 | 10004 视为正常态；40401 显示不存在空态；ABORTED 不请求报告，直接「已中止，无报告」；未结束会话提示回房间；其他错误显示 ErrorState + traceId + 重试 |
| 维度口径 | 固定顺序 `technical/depth/logic/match/communication/voice`；TEXT 排除 voice，AUDIO 缺失 voice 时提示而非补 0；分数 clamp 0~100；色带 <60 红、60~74 橙、75~84 蓝、≥85 绿 |
| 总分环 | 纯 SVG + `stroke-dashoffset`，不引 ECharts；中心显示 `toFixed(2)` 与等级（待提升/合格/良好/优秀） |
| 雷达 | 按需注册 ECharts（Radar/Tooltip/Legend/Canvas）；max=100、splitNumber=4、中文轴标签、面积半透明；`ResizeObserver` 跟随侧栏/窗口变化；<3 维显示空态 |
| 逐题证据 | 按 `roundNo` 升序；默认展开首题、可多题同开、可折叠；覆盖得分点绿色、失分点红色、证据句引用块、理由必显；空数组明确文案；AUDIO 场按 `roundNo` 对齐消息的 `audioPath` 展示回放 |
| 音频回放 | `fetchAudioBlob` 携带 JWT → `URL.createObjectURL` → 单实例 `Audio`；切换自动暂停、卸载释放 URL；格式不支持/文件过期展示中文降级文案 |
| 推荐预览 | 仅取 Top2 技能 + 首条资源/练习；失败显示「不影响报告」的降级提示，完整推荐 CTA 仍可跳 `/recommendations?positionId=` |
| 历史列表 | 服务端分页 10/20/50；状态筛选（全部/进行中/已完成/已中止）仅作用于当前页并标注；FINISHED/TIMEOUT → 查看报告，进行中 → 继续面试，ABORTED → 重新开始；空态/错误态/越界回退 |
| URL 同步 | `page/size/status` 与路由查询同步；深链接越界自动回退最后一页并纠正 URL；size 变化回第 1 页；使用 `router.replace` 不污染返回栈 |
| 隐私 | 登出/切换账号时 `reportStore.clearAll()`，避免跨账号复用同一 sessionId 的内存缓存 |

### 边界与降级手工/自动验证

- **TEXT/AUDIO 报告**：demo01 会话 21（TEXT，64.46，5 维）与 4（AUDIO，62.90，6 维含 voice=60.0）均从真实后端加载；雷达/维度条一致。
- **10004**：`page.route` 强制首个响应 10004，页面显示「报告生成中」，1s 后自动恢复；无误报全局错误。
- **60s 重试**：`page.clock` 快进 61s →「报告生成较慢或失败」；点击「重新生成报告」→ 仅 1 次 finish → 报告恢复；对应后端幂等入口。
- **中止**：`/interview/1/report` → 「该面试已中止，无报告」+ 重新开始/返回历史；不请求 report。
- **未结束会话**：新建 CREATED/WAITING 会话直接访问报告 URL → 「本场面试尚未结束」+ 回房间；不会无意义轮询。
- **40401**：不存在/无权限会话 → 不存在空态 + 返回历史（复用 F2 的 40401 手工路径）。
- **音频回放失败**：开发库音频为 fake bytes，点击回放后 `play()` 失败 → 中文提示「音频格式不受支持或文件已过期，暂时无法回放」，不抛出 pageerror（截图 04c）。
- **推荐接口失败**：报告页推荐区局部提示，报告其余内容正常（F2 首页降级用例同口径）。
- **历史越界**：URL `page=99` 时 `usePagination` 请求返回 pages 后回退最后一页并纠正 URL（单测覆盖，E2E 分页覆盖正常路径）。
- **账号切换**：登出/换号时清空报告缓存；`clearAll` 单测覆盖。

## 6. 与计划的偏差与说明

| # | 偏差/说明 | 原因/处理 |
|---|---|---|
| 1 | 房间 FINISHED/TIMEOUT 仍停留在终态面板，不自动跳转报告页 | 保留 F2 已验证的终态反馈与 E2E 行为；报告页独立负责 10004 轮询/重试，房间「查看报告」CTA 已可达。计划 §7.8 允许报告页先显示生成中 |
| 2 | 报告 store 增加 `clearAll`，在 `App.vue` 监听 token 变化清空缓存 | 内存缓存跨账号可能复用同一 sessionId 的报告；清空满足隐私要求（计划 §6.8） |
| 3 | 历史状态筛选为客户端当前页筛选并标注 | 计划 §5.9 明确「仅当前页，标注」；服务端分页仍由 `page/size` 保证 |
| 4 | F3 E2E 串行执行、报告用例共享 E2E 用户；历史用例单独用户 | 后端登录限流 5 次/分钟/IP；此策略使全套 10 条 E2E 稳定在限流内，且不污染 demo01 |
| 5 | 重试用例用 `page.clock` 快进 60s，而非真实等待 | 保持用例稳定且不拖慢 E2E；真实计时逻辑由 `stores/report` 单测覆盖 |
| 6 | ReportView 懒加载 chunk 462.83KB / gzip 157.58KB（含 ECharts） | ECharts 按需注册且仅报告页加载；首屏主包未引入。F6 可再做 echarts vendor chunk 拆分/体积审计 |
| 7 | 提前结束的面试：逐题证据数可能小于计划轮次；历史「轮次」显示实际 `currentRound+1 / plannedRounds` | 后端 `currentRound` 在提前 finish 时不强制推进到 planned；前端不伪造 N/N，报告头部同时展示「X 题证据」与「计划 N 轮」 |
