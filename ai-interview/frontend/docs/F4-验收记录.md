## 2. 核心实现口径

| 主题 | 落地 |
|---|---|
| 录音能力检测 | 复用 `useInterviewCapabilities`：MediaRecorder + getUserMedia + `audio/webm;codecs=opus`（回退 `audio/webm`）+ 构建开关 `VITE_ENABLE_AUDIO`；缺失时给出具体原因并引导新建文字面试 |
| 权限与设备错误 | `NotAllowedError/SecurityError` → 权限被拒；`NotFoundError` → 无设备；`NotReadableError` → 被占用；`OverconstrainedError` → 参数不满足；均中文提示且不误清空上一次录音 |
| 录音生命周期 | 首次点击才 `getUserMedia`；`start(1000)` 分片；计时用 `Date.now()` 差值（200ms 刷新）；600s 自动停止并保留结果；累计 >10MB 自动停止并丢弃结果；停止/重录/卸载都 `track.stop()` 释放 MediaStream |
| 单录音实例 | `AudioRecorder` 内部持有唯一 `useAudioRecorder`；`AudioAnswerPanel` 只通过 `recorded/started/stopped` 事件接收 blob/时长，避免双实例导致"有录音但提交按钮禁用" |
| 转写 | Web Speech `zh-CN/continuous/interimResults`；final 累加、interim 独立显示；`onend` 自动重启最多 3 次；`not-allowed/service-not-allowed/audio-capture` 不再重启；`network` 直接提示离线手工转写（避免断网 3 次无意义重试）；不支持时 textarea 手工填写 |
| 转写可编辑 | 录音结束后 textarea 可修正；用户一旦手工编辑（`edited=true`），后续识别结果不再覆盖；`pauseCount` 由 `speechend` 次数估算，可选上送（后端 D19 不落库） |
| 音频提交 | `FormData`：`file`（webm）+ `roundNo` + `asrText` + `durationMs` + `pauseCount?`；本地先校验 1~5000 字 / 1~600000ms / ≤10MB（与后端同口径），失败不发请求；受理后与文字共用 `PROCESSING_AI → WS/轮询对账`；失败保留 blob 与转写，不自动重发 |
| TRANSCRIPT 对账 | WS `TRANSCRIPT {messageId, asrText}` 按消息 ID 回填 `asrText`；页面仍以 `GET messages` 为权威（D32）；E2E 等待服务端 USER 音频消息落库后才 finish，避免"乐观气泡已见、报告 0 题"的竞态 |
| 房间回放 | 仅 `inputType=AUDIO && audioPath` 的消息显示"回放录音"；`fetchAudioBlob` 带 JWT，blob URL + 单实例 Audio；一次只播一个；卸载/终态停止并 revoke；失败中文降级 |
| 录音中离开 | `onBeforeRouteLeave` 检测录音中弹二次确认（停止并离开 / 继续录音）；`openFinish/openAbort` 先停止录音再弹确认；`beforeunload` 继续由房间提交态兜底 |
| 成长曲线 | `time` 轴 + 每技能一条折线 + `connectNulls:false` + legend 可滚动 + y 0~100；`utils/growth` 清洗/排序/current/delta；单点也显示 symbol；切岗位写 `?positionId=`，深链接非法回退首个启用岗位；空态/错误态/traceId；`useEchart` 卸载 dispose |
| 学习推荐 | Top3 按 priority 降序；短板理由/资源/练习/错题重练/下场建议逐项空态；资源外链仅 http(s) 渲染为 `<a target=_blank rel=noopener noreferrer>`，其余降级纯文本；错题用 `<details>` 展开题干与缺失点；"开始下一场"解析 `nextInterviewSuggested` 的难度（解析失败仅带岗位），设置页读取 `?difficulty=` |
| 个人中心 | 账号卡展示用户名/真实姓名/专业/角色/状态/ID，不展示密码/散列；`PUT /users/me` 保存后 `auth.applyUser` 同步内存与 localStorage；未变更/超长禁用保存；退出二次确认 → `POST logout` → 清本地 → 登录页 |
| 隐私 | 音频只经鉴权接口回放，不暴露静态 URL；页面不展示 token/password；登出清空 auth 与报告缓存（沿用 F1/F3） |

## 6. 偏差与遗留

| # | 事项 | 说明/后续 |
|---|---|---|
| 1 | E2E 使用注入的假 MediaStream/MediaRecorder，而非真实麦克风 | 本机 macOS + 系统 Chrome（headless/headed）即使加 `--use-fake-device-for-media-stream --use-fake-ui-for-media-stream`，`getUserMedia` 仍 5s 超时；按计划 §5.7.5/§9.4 允许的"伪造麦克风或手工转写"路径，E2E 注入假设备，覆盖录音 UI/计时/提交/回放请求；**真实麦克风权限与声音采集需在答辩机 Chrome 手工复验一次**（P19） |
| 2 | 假 blob 不是真实 Opus 音频 | E2E 只断言回放请求 200 + `audio/*` 与错误降级，不宣称可听见声音；真实录音回放由 F3 的 `useAudioReplay` 单测 + 真实浏览器手工验收覆盖 |
| 3 | 成长截图每技能仅 1 个记录点 | 截图账号只完成 2 场且同日，时间轴跨度小；曲线/图例/技能卡均正确，真实多场演示会形成多段折线 |
| 4 | ASR `network` 错误不自动重启 | 计划允许 onend 最多重启 3 次；为避免断网时 3 次无意义重试与提示刷屏，网络错误直接停止并引导手工转写（权限/服务错误同样不重启），其余 `no-speech` 仍按 3 次上限重启 |
| 5 | composables 未纳入覆盖率统计 | 当前 coverage include 仅 api/stores/utils（沿用 F3 配置）；F6-1 再扩到 composables/components/views 并做 70/60 门禁 |
