## 2. 核心实现口径

| 主题 | 落地 |
|---|---|
| 管理外壳与权限 | 7 个菜单：看板、岗位、评分权重、题库、知识库、学习资源、用户；`activeMenu` 支持 `/admin/positions?tab=weights` 的高亮；学生访问任意 `/admin/*` 由守卫跳 `/403`，刷新通过 `auth.restore` 保持；`/admin/evaluation` 重定向到 `/admin/positions?tab=weights`（D33） |
| 看板 | `GET /admin/dashboard` 四卡（用户数/场次/题量/均分）；场次=`started_at` 非空、均分=已出分场次、题量含逻辑删并在页面注明口径；`avgScore=null` 显示「—」；近 7 日柱=场次（左轴）、线=均分（右轴），`connectNulls:false` 断点；刷新独立请求，失败保留旧数据并提示 |
| 题库 CRUD | 岗位/题型/难度筛选 + 分页与 URL 同步（越界回退最后一页）；新增/编辑携带 `version`，编辑成功后 version+1；删除二次确认 → `DELETE`（逻辑删 DISABLED，行保留）；得分点/失分点/追问模板使用每行一条编辑器，超 10 条阻止保存 |
| 40003 冲突恢复 | 编辑携带旧 `version` → 后端 `40003` → 提示"数据已被他人修改" → 重新拉取该题最新版本（后端无单题 GET，按 `positionId` 分页查找）→ 展示本地/最新版本、修改时间与最新题干 → `[用我的内容覆盖]` 以最新 version 重新提交 / `[放弃我的修改]` 关闭并刷新；不静默丢弃输入 |
| 岗位与技能权重 | 新增/编辑/查看；`code` 创建后只读、不提供删除；`SkillWeightsEditor` 动态行、实时合计、重复编码提示、至少 1 行；技能权重和=1±0.01；`defaultRounds` 3~8；保存后回读；停用后学生端岗位列表不可见 |
| 评分权重 | 内容 5 项/表达 5 项/总分 4 项；三组均必填、0~1、组内和=1±0.01；实时显示差值与错误；保存提交完整三组并回读；`reset` 回填与后端一致的默认权重；未显式配置时展示默认值并提示"保存后写入"；仅影响后续面试 |
| 资源 CRUD | 岗位/技能/类型筛选 + 分页 URL 同步；技能下拉随岗位能力模型联动；新增/编辑全量提交；DELETE=下架 `enabled=0`，已下架仍可编辑重新启用；链接可选且只接受 http(s) |
| 用户管理 | 用户名/真实姓名关键词搜索 + 分页 URL 同步；启用↔禁用二次确认并刷新行状态；当前登录账号标记「当前」且开关禁用（后端 40001 兜底）；无新增/删除 |
| 知识库 | 仅新增片段 + 重建索引，页面明确"后端无列表/编辑/删除接口"，不渲染假列表；标题 2~200、内容 10~8000、keywords 4~500、技能标签多选对齐岗位；新增成功回显 ID/岗位/技能/关键词；重建二次确认并展示 `rebuilt:true` |
| 视觉与响应式 | 全部页面复用 `GlassPanel`/`AppBackdrop`/Element Plus 玻璃化；1440 下表格与筛选完整；<768 管理端顶部提示"建议桌面端"，表格在卡片内部横向滚动，不撑破页面；表格操作列使用 flex 不换行 |
| 错误与状态 | 每页覆盖加载骨架、空态、错误态（含 traceId）、无权限全局 403、离线提示；`ElMessage`/表单内联错误提示 40001/40401/40003 |

## 6. 偏差与遗留

| # | 事项 | 说明/后续 |
|---|---|---|
| 1 | 题库 40003 恢复使用列表接口查找最新版本 | 后端未提供 `GET /admin/questions/{id}`；按 `positionId` 分页查找到该 id（100/页，必要时翻页）。不新增后端接口（计划禁令），页面在冲突弹窗中展示最新版本号/修改时间/题干 |

| 4 | E2E 数据无法全部通过 API 清理 | 岗位无删除接口、知识片段无删除接口；验收后用 SQL 清理，命令见 §7。F6-6 可固化为 `qa/cleanup_e2e_data.sh` |
