### 5.4 部署缺陷修复（F6 实测发现）

1. **首页 404**：`location = /index.html` 只写 `add_header`，未继承 `root`，`try_files` 内部跳转到该 location 时去默认路径找文件 → 404。修复：`root /usr/share/nginx/html` 提到 server 级。
2. **favicon 403**：宿主机 `public/favicon.svg` 权限 0600，`COPY` 保留权限，Nginx worker 非 root 不可读。修复：镜像内 `RUN chmod -R a+rX /opt/frontend-dist`。

> 两个问题均在本次验收中复现并修复后复验；P9（默认页）未回归。
